# Minecraft-2D
# ⛏️ Minecraft 2D — Python Edition

> Полноценная 2D-версия Minecraft на Python + Pygame: бесконечный мир, мобы, деревни, магазины, оружие, голод и финальная цель.

## 📖 О проекте

Ты — обычный игрок в Minecraft. Однажды ночью, исследуя старую шахту, ты наткнулся на странный портал. Ты шагнул в него... и очнулся здесь. Этот мир похож на твой, но что-то не так. Здесь есть деревни с торговцами, странные монеты и опасные мобы, которые выходят по ночам.

**Чтобы вернуться домой, ты должен собрать 5 алмазов 💎 и 50 монет 🪙 и найти путь назад через древний портал.**

## ✨ Возможности

### 🌍 Мир
- **Бесконечная генерация чанков** — мир создаётся на лету по мере движения
- **5 биомов**: Равнины 🌾, Лес 🌲, Пустыня 🏜️, Снега ❄️, Горы ⛰️
- **Процедурные пещеры** и **рудные жилы** (уголь, железо, золото, алмазы)
- **Деревья с кроной**, **кактусы**, **падающие блоки** (песок, гравий)
- **Цикл дня и ночи** с движением солнца и луны
- **Параллакс-облака** на фоне
- **Плавная камера** следит за игроком

### 🎮 Геймплей
- **❤️ Здоровье** (10 сердец) с регенерацией при сытости
- **🍗 Голод** (10 ножек) — тратится при движении, приводит к смерти
- **⚔️ Боевая система** с отбрасыванием мобов
- **🎒 Инвентарь** и **хотбар** на 9 слотов
- **💀 Система смертей** с причиной и статистикой
- **🏆 Финальная цель** — экран победы со статистикой и рангом
- **🌊 Физика воды** и плавания

### 🏘️ Деревни

Каждая деревня (12% шанс на чанк) содержит:
- 🏠 **Дом** с деревянными стенами, крышей и дверью
- 📦 **2 сундука** с лутом (монеты, еда, оружие, иногда алмазы)
- 🛒 **Ларёк** с магазином (10 товаров)
- 🛣️ **Gravel-дорога** на поверхности

### 💰 Экономика

- **🪙 Монеты** — старт 10 шт., падают с мобов и находятся в сундуках
- **💎 Алмазы** — добываются на глубине Y > 78 или в сундуках (15%)
- **🛒 Ларёк** — покупай еду, оружие и кирки за монеты

### 🔒 Секретная консоль

Для команды разработчиков — открывается клавишей **`~`** (тильда, слева от «1»).

> 💡 Убедись, что у тебя **Python 3.8+** и **Pygame 2.0+**


## 🕹️ Управление

| Клавиша | Действие |
|---------|----------|
| **A / D** или **← / →** | Ходить влево / вправо |
| **SPACE / W / ↑** | Прыжок / всплытие в воде |
| **ЛКМ** | ⛏️ Копать блок / ⚔️ Атаковать моба |
| **ПКМ** | 🧱 Ставить блок / 🍖 Есть / 📦 Открыть сундук / 🛒 Ларёк |
| **E** | Открыть ближайший ларёк |
| **1–9** или **колесо мыши** | Выбрать предмет в хотбаре |
| **R** | Возродиться после смерти |
| **F11** | Полный экран / окно |
| **ESC** | Выход / закрыть магазин |
| **`** (тильда) | 🔒 Открыть dev-консоль |

## 🎯 Как победить

1. 🌅 **Днём** охоться на свиней, коров, овец — получай еду
2. 🏘️ **Найди деревню** — обыщи сундуки, там монеты и снаряжение
3. ⛏️ **Копай на глубине Y > 78** — ищи алмазную руду
4. 🛒 **Торгуй в ларьках** — купи железный или алмазный меч
5. 🍗 **Не забывай есть!** Голод = смерть
6. 💎 **Собери 5 алмазов** и **50 монет** — откроется портал домой!

## 🏅 Система рангов

Итоговый ранг зависит от количества смертей за прохождение:

| Смертей | Ранг | Цвет |

| 2–4 | 🥈 **A** | Зелёный |
| 5–9 | 🥉 **B** | Оранжевый |

## 🛠️ Технические детали

| Параметр | Значение |
|----------|----------|
| **Движок** | Pygame 2.x |
| **Язык** | Python 3.8+ |
| **Графика** | Процедурные текстуры (без внешних ассетов) |
| **Звук** | Отсутствует (можно добавить через `pygame.mixer`) |
| **Размер мира** | Бесконечный (чанки 16 × 96 блоков) |
| **Производительность** | Стабильные 60 FPS |
| **Разрешение** | Автоматически — полный экран |
| **Зависимости** | Только `pygame` |


### Как это работает
- **Чанки** генерируются лениво и кэшируются в словаре
- **Шум Перлина** (собственная реализация FBM) отвечает за рельеф
- **Биомы** определяются по 3 картам шума (высота, температура, влажность)
- **Физика** — собственная реализация коллизий AABB
- **Рендер** — только видимые чанки (~5 штук одновременно)
